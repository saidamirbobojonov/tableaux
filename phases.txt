  [BUG 1] OrderItem.selected_modifiers field missing
    - File: apps/orders/models.py
    - Serializer calls .set(modifiers) on a field that does not exist in the DB.
    - Creating any order with modifiers currently raises an AttributeError / 500.
    - Fix: Add ManyToManyField to Modifier + create migration 0003.

  [BUG 2] Analytics get_top_items() ignores date_to
    - File: apps/analytics/services.py
    - get_top_items() applies date_from filter but never applies date_to.
    - Owner sees wrong data when filtering by date range.
    - Fix: Add missing qs.filter(created_at__date__lte=self.date_to) block.

  [BUG 3] Inventory app has no URL endpoints
    - App has complete models (Ingredient, Supplier, StockBalance, PurchaseOrder)
      but zero API endpoints are exposed.
    - Staff cannot add ingredients, view stock levels, or create purchase orders.
    - Fix: Create serializers.py + views.py + urls.py for inventory app,
      register under /api/v1/inventory/ in config/urls.py.

  [BUG 4] RBAC not enforced in any view
    - All views only check IsAuthenticated — any logged-in user can hit any endpoint.
    - A WAITER can view owner analytics. A CHEF can close shifts.
    - Fix: Create apps/users/permissions.py with role-based DRF permission classes,
      apply correct permissions to analytics, kitchen, shifts, and orders views.

  [BUG 5] Kitchen app not registered in config/urls.py
    - apps/kitchen/urls.py exists but is never included in the main router.
    - /api/v1/kitchen/ returns 404 for all requests.
    - Fix: Add path("api/v1/kitchen/", include("apps.kitchen.urls")) to config/urls.py.
